# milo calculator

A responsive, keyboard-friendly calculator built with plain HTML, CSS, and JavaScript. No build step or dependencies are required.

Open `index.html` in a browser to use it. The calculator supports addition, subtraction, multiplication, division, percentages, decimals, sign changes, backspace, and a recent-calculations list.

Keyboard shortcuts: use number and operator keys to enter a calculation, `Enter` or `=` to calculate, `Backspace` to delete, and `Escape` to clear.
