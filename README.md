# milo calculator

A responsive, keyboard-friendly calculator built with plain HTML, CSS, and JavaScript. It includes a dark/light theme switch, a scientific keypad, DEG/RAD angle modes, and recent calculations. No build step or dependencies are required.

Open `index.html` in a browser to use it. The standard keypad supports addition, subtraction, multiplication, division, percentages, decimals, sign changes, and backspace. Expand **Scientific** for trigonometry, square roots, logarithms, powers, parentheses, and π.

Keyboard shortcuts: use number and operator keys to enter a calculation, `Enter` or `=` to calculate, `Backspace` to delete, and `Escape` to clear.
